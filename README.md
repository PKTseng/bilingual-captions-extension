# bilingual-captions-extension

> 📖 **第一次使用、沒有寫過程式？請直接看 [使用教學.md](使用教學.md)**，一步一步教你安裝和設定。

在桌面版 Chrome 的 YouTube 播放器同時顯示原文（英文、日文、韓文或泰文）及繁體中文字幕。預設由 Chrome 在本機翻譯，首次使用可能需要下載語言模型；也可改用 AI 翻譯（見「翻譯等級」）。

## 安裝或更新

將 ZIP 解壓至 Side_Project。若已安裝舊版，可以用新版檔案更新原目錄，再到 chrome://extensions 點套件卡片上的重新載入。新安裝則開啟開發人員模式，選「載入未封裝項目」，指定專案資料夾。完成後重新整理 YouTube。使用說明可從工具列小視窗的「使用說明」打開。

## 使用

- 將滑鼠移到影片上，點右下角控制列的雙語字幕圖示，會在圖示上方打開「雙語字幕選單」（外觀仿 YouTube 的設定選單）。打開「雙語字幕」開關，然後播放。圖示下方有底線時表示雙語字幕開啟中。
- 再點一次圖示、點選單外面或按 Esc 都會關閉選單；打開或關閉選單本身不會開關字幕。
- 在 YouTube 影片頁按 **Alt+C** 可直接開啟或關閉雙語字幕。游標在文字輸入欄位時，快捷鍵不會觸發。
- 點瀏覽器工具列的擴充功能圖示（可先從拼圖選單釘選）會打開小視窗：可開關雙語字幕、選原文語言，並顯示目前分頁的原文、字幕來源與翻譯狀態；也有設定頁與使用說明的捷徑。
- 選單各列：
  - **雙語字幕**：開關雙字幕。
  - **字幕顯示**可選「雙語」（預設）、「只顯示中文」或「只顯示原文」。播放中可切換，下次看影片會沿用。只看原文時會停用翻譯。
  - **原文語言**：「自動」（預設）、「英文」「日文」「韓文」或「泰文」，見「原文語言」。
  - **字幕大小**可同步縮放原文和繁中字幕，從 75% 到 200%。開啟雙語字幕後，按 `+` 放大一級、`-` 縮小一級、`0` 恢復預設的 125%。大小會自動儲存。
  - **翻譯**：右側顯示目前的翻譯等級與模型，例如「AI · deepseek-v4.1-flash」，點進去可切換等級（見「翻譯等級」）。
  - **字幕時間**：右側顯示「原始」或「提早 0.5 秒」等，點進去可微調（見下文）。沒有時間碼時無法選取。
  - **匯入原文 SRT／VTT**：選擇字幕檔。
  - **API key 與模型設定…**：打開擴充功能的設定頁。
  - 最底下的小字顯示目前的字幕來源，以及是否含字詞時間碼。
- 套件會打開播放器 CC，沿用播放器字幕請求的憑證，直接下載原文字幕軌（json3，毫秒級時間碼）。同一種語言有人工字幕時優先使用，沒有才用自動產生的字幕。播放器畫面上選的是哪種語言都不影響，並會提前翻譯接下來約一分鐘的句子。
- 讀不到字幕軌時，會改讀 YouTube 逐字稿面板（只有秒級時間碼）。再讀不到，才用播放器 CC 即時合句，這時字幕會比聲音晚，因為要等句尾或停頓。
- 若播放器讀不到字幕，可用 DownSub 下載原文 SRT。在提示卡或選單中點「匯入原文 SRT／VTT」，選擇檔案。雙語字幕已開啟時會直接套用。
- 雙語字幕預設關閉。手動開啟後，同一個 Chrome 設定檔的 YouTube 分頁會同步啟用，換片、重新整理或重開瀏覽器也會沿用。遇到沒有字幕的影片，下一部有字幕的影片仍會自動顯示。從選單或按 Alt+C 手動關閉後，這個選擇也會保留。

從字幕軌取得的字幕會依實際字詞時間斷句：人工字幕依標點斷句，句子落在一行中間時，依字元位置推算該行內的時間；自動字幕沒有標點，但每個字都有時間碼，會在說話停頓處斷句，句子過長時切在後半段最長的停頓。每句從第一個字開始時出現，最後一個字講完後停留約 0.6 秒，或在下一句開始時換掉。

SRT 和 YouTube 逐字稿會先按句子重新組合，再依時間碼整句顯示。逐字稿的結束時間會依下一段起點推算。若兩句共用一個字幕片段，分界會在該片段的時間內估算。有時間碼時，完整原文會在起始時間顯示，繁中翻好後只補到仍在畫面上的同一句。缺少時間碼時，即時 CC 需要接到句尾或停頓後才能顯示整句。

選單最底下的小字顯示目前字幕來源。播放時間碼字幕時，可在選單的「字幕時間」把字幕提早或延後，每次 0.5 秒，最多 ±10 秒；「重設」回到原始時間碼。切換影片會重設微調。若使用即時 CC，套件會在下一句開始收到文字時移除前一句，再等待下一整句。

## 原文語言

選單的「原文語言」決定拿哪一種字幕當原文，也可從工具列小視窗選，所有分頁同步：

- **自動**（預設）優先採用 YouTube 標示的原始音軌語言。沒標示時，會依自動字幕推斷；若有多種自動字幕語言，則優先找英文。選定語言後，只下載該語言的字幕軌。選單會顯示目前語言，例如「自動 · 英文」。
- **英文／日文／韓文／泰文**：只用這個語言的字幕軌；影片沒有時，改讀逐字稿面板或即時 CC。

播放中改選會重新載入字幕。逐字稿、即時 CC 與匯入的檔案沒有標示語言，會依文字判斷（假名為日文、諺文為韓文、泰文字母為泰文）。日文不以空格分詞：句子在「。！？」處斷開，沒有句號的人工字幕每行各成一句，行與行直接相接；自動產生的日文字幕依停頓斷句。

Chrome 內建翻譯依原文語言建立翻譯模型，可能需要另外下載；若 Chrome 不支援這個語言翻繁中，會只顯示原文並提示改用 AI。AI 翻譯不受限制。

## 翻譯等級

在選單點「翻譯」，可以直接選擇 Chrome 內建翻譯或 AI 模型。目前使用的選項會打勾，播放中切換會立即生效：

- **基本**：Chrome 內建翻譯，在本機執行，不需要 API key。
- **AI**：透過 OpenRouter 呼叫 AI 模型，預設為 DeepSeek（`deepseek/deepseek-v4.1-flash`），依用量計費，一部 10 分鐘的影片約 0.2 美分。以整段字幕為單位分批翻譯，語氣較自然，換句時通常已翻好。剛開始或跳轉後先送約 8 句，讓第一句盡快出現，之後每批約 20 句。選單裡也可改用 Qwen 或 Claude Sonnet 等其他 OpenRouter 模型。

選用 AI 時，Chrome 會同步翻譯畫面上這一句。若 Chrome 先完成，字幕會先顯示本機譯文，等同一句的 AI 譯文到達再自動替換，暫停播放時也會更新。若 Chrome 提示下載語言模型，可點播放器的下載按鈕啟用本機譯文，AI 翻譯會繼續進行。

第一句 AI 譯文顯示時，字幕上方會短暫提示「已切換為 AI 翻譯」。接下來的字幕沿用同一個模型時，提示只出現這一次。

AI 翻譯的其他行為（在設定頁的「AI 翻譯（OpenRouter）」區塊調整）：

- **影片資訊**：每批字幕會附上影片標題、頻道與說明的前 300 字（去掉網址與 hashtag），讓 AI 判斷主題和專有名詞的寫法。
- **詞彙表**：每行一個詞，「LLM = 大型語言模型」（也可用 `→` 或 `->`）指定譯法，只寫「Kubernetes」代表保留原文，`#` 開頭的行略過。只有這批字幕出現的詞才會送出（英數詞依整個字比對，「AI」不會配到「said」）。只用於 AI 翻譯。
  看《七騎士 Re:BIRTH》時，AI 會依影片標題、頻道名稱，或說明中的遊戲標籤啟用本機韓文／泰文對繁中詞庫，涵蓋英雄、技能、狀態、裝備、寵物、造型與副本。未自動辨識時，可在 Dual 選單開啟「本片七騎士詞表」，也可手動關閉。換片會重新判斷。個人詞彙表優先，單一原詞有多種繁中譯法時交給模型依上下文判斷。

  資料取自 [7Knights Hub](https://www.7knightshub.com/) 的公開圖鑑。[三語 JSON](data/seven-knights-terms.json) 的每列依序是韓文、泰文、繁中。遊戲更新後可執行 `python scripts/fetch-seven-knights.py <新的暫存目錄>` 從公開索引重建。詞庫內容變更會使用新的譯文快取。觀看影片時只讀取擴充功能內附的檔案。
- **修正自動產生的字幕**（預設開啟）：字幕軌是自動產生的時，AI 會同時回傳補上標點、改正明顯聽錯字的原文，畫面上的原文會換成修正版，複製單字時也是修正後的字。改動太大（像是改寫）的修正會被忽略。
- **在背景翻完整部影片**（預設開啟）：有時間碼的影片播放超過 1 分鐘後，會從目前位置往後、再從開頭，一批一批（每批約 20 句，批次間隔 0.5 秒）翻完其餘句子並存起來，之後跳轉不用等。某批失敗時就停止，其餘句子照常在播放到時才翻。

改詞彙表或「修正自動產生的字幕」會讓 AI 的譯文不同，所以已存的譯文會分開保存，播放中改了也會立即改用新設定。

### AI 用量與每月上限

OpenRouter 每次回覆都會附上這次請求的費用（`usage.cost`，單位是 credits，1 credit 為 1 美元）與 token 數。背景程式會把它們按月（本機時間）累計，存在 `chrome.storage.local` 的 `bceUsage`，只保留本月與上一次有使用的月份。只算這個 Chrome 透過本套件送出的請求，實際帳單以 OpenRouter 的 Activity 頁為準。

- 設定頁的「AI 用量與每月上限」顯示本月與上次使用月份的費用、請求數與 token 數，並可設定**每月上限**（美元，留空或 0 為不限）。
- 工具列小視窗會顯示本月 AI 費用，有設上限時一併顯示。
- 本月費用達到上限後，背景程式不再送出 AI 請求，回 `budget`；播放器改用 Chrome 內建翻譯並提示，「翻譯」子選單的 AI 模型會標示「已達本月上限」並停用。下個月或調整上限後即可再用（調整後在選單重新選 AI）。已送出的請求仍會完成，整部預翻也受同一個上限限制，所以費用可能略超過上限。


舊版的「AI 免費」（Gemini）與「AI 進階」已合併為「AI」；原本選了其中一個的設定會自動改成「AI」並使用 DeepSeek。

API key、模型與預設等級在擴充功能的設定頁設定：在選單點「API key 與模型設定…」，或到 chrome://extensions → 雙語字幕 → 詳細資料 → 擴充功能選項。在設定頁改了模型，選單上的標籤會跟著更新。OpenRouter 名稱以 `:free` 結尾的模型有次數限制，用完時請求會失敗。

使用「載入未封裝項目」安裝時，也可在 `manifest.json` 同一層建立 `.env`，填入 OpenRouter 金鑰：

```dotenv
OPENROUTER_API_KEY=
```

會優先使用 `.env` 的非空白金鑰，留白時使用設定頁存過的值。舊的 `GEMINI_API_KEY` 會被忽略，可以刪除。初次更新程式後請在 `chrome://extensions` 重新載入擴充功能，再重新整理 YouTube。`.env` 已加入 Git 忽略清單，製作分享用 ZIP 時也請排除這個檔案。

在設定頁的「播放器模型選單」可勾選要顯示的內建模型。按「儲存」後，已開啟的播放器選單會同步更新。自行輸入的模型也可以選擇。「測試翻譯」會儲存設定，並用和播放器相同的流程翻譯兩句測試字幕；失敗時會顯示原因，例如「測試失敗：AI 服務暫時無法使用（HTTP 503）。」預設清單由 `settings.js` 的 `MODEL_CATALOG` 定義，隨套件新版發布。

服務暫時過載（HTTP 502／503／504）時，背景程式會在 1 秒、3 秒後各自動重試一次；包含重試在內，一次請求最多等 25 秒。AI 翻譯失敗時（沒有 key、key 無效、超過次數限制、網路錯誤、超過 25 秒沒有回應等），套件會自動改用內建翻譯並顯示提示（約 6 秒後自動消失），字幕不會中斷。若 Chrome 需要下載語言模型，請點播放器提示中的下載按鈕，完成後會自動接續翻譯。若內建翻譯也無法啟動，可切到「只顯示原文」繼續觀看。退回後，選單的「翻譯」仍會顯示所選的 AI 模型，下一行會標示失敗原因與目前狀態，例如「AI 回應逾時，改用 Chrome 內建」「找不到這個模型，改用 Chrome 內建」或「API key 無效或沒有權限，僅顯示原文」。若顯示「擴充功能已更新，請重新整理頁面」，代表擴充功能重新載入過，重新整理 YouTube 頁面即可。在「翻譯」子選單再點一次原本的 AI 等級即可重試。選擇 AI 等級時，原文字幕與影片標題、頻道、說明會送到 OpenRouter 翻譯；API key 只保存在本機，只有背景程式與選項頁會讀取。

AI 譯文會依「影片＋模型」保存在本機（`chrome.storage.local`，只有擴充功能讀得到）。重看同一部影片、重新整理頁面或跳回看過的段落時，已翻好的句子會直接顯示，不會再送到 OpenRouter，也不會再收費；只有還沒翻過的句子才會送出。AI 修正過的自動字幕也一起保存。換模型、詞彙表或修正設定都會分開保存。翻譯的提示詞改版時，舊版存下的譯文不再使用（「清除已存的譯文」仍會刪掉它們）；這一版調整了韓文口語和遊戲專名的翻譯指示，所以更新後看過的影片會重新翻譯一次。最多保留最近使用的 300 筆（約數 MB），超過時刪掉最久沒看的影片。在設定頁的「已存的 AI 譯文」可以看到目前存了多少，也可以全部清除。Chrome 內建翻譯在本機執行又不收費，所以不另外保存。

HTTP 429 回應會提示服務限制請求，模型仍可手動重試。OpenRouter 回傳 HTTP 402（帳戶餘額不足）時，會提示餘額不足並改用 Chrome 內建翻譯，同一個服務商的所有模型都會在翻譯子選單標示並停用；因同時進行中的請求暫時超出餘額而回的 402 則視為限制請求。加值後，可重新整理影片頁面再試。更新 API key 也會解除本頁的停用狀態。

## 查單字、複製、重播

- 滑鼠移到字幕上時，該句會暫停換句（影片照常播放），移開後跳回目前的句子。
- 字幕左側同時會出現「重播這句」按鈕，按一下從這句開頭（提前 0.2 秒）重新播放；影片原本暫停的話也會開始播放。字幕時間有提早或延後時會自動扣回。直播和沒有時間碼的字幕不會顯示這個按鈕。
- 點一下原文單字或中文詞就會複製該字；拖曳選取一段文字會複製選取的部分；連點三下複製整行。
- 複製後字幕上方會短暫顯示「已複製：…」。點字幕不會讓影片暫停或全螢幕，右鍵會出現瀏覽器的選單。

## 匯入字幕

在選單點「匯入原文 SRT／VTT」可匯入字幕檔，會依檔案的時間碼斷句；語言依「原文語言」，選「自動」時依檔案文字判斷。只有即時 CC 時，要等字幕送到才能合成整句。逐字稿時間區間有空檔時，若播放器當下仍有 CC，會用當前 CC 補位。
