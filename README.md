# bilingual-captions-extension

> 📖 **第一次使用、沒有寫過程式？請直接看 [使用教學.md](使用教學.md)**，一步一步教你安裝和設定。

在桌面版 Chrome 的 YouTube 播放器顯示英文及繁體中文字幕。預設由 Chrome 在本機翻譯，首次使用可能需要下載語言模型；也可改用 AI 翻譯（見「翻譯等級」）。

## 安裝或更新

將 ZIP 解壓至 Side_Project。若已安裝舊版，可以用新版檔案更新原目錄，再到 chrome://extensions 點套件卡片上的重新載入。新安裝則開啟開發人員模式，選「載入未封裝項目」，指定專案資料夾。完成後重新整理 YouTube。

## 使用

- 將滑鼠移到影片上，點右下角控制列的雙語字幕圖示，會在圖示上方打開「雙語字幕選單」（外觀仿 YouTube 的設定選單）。打開「雙語字幕」開關，然後播放。圖示下方有底線時表示雙語字幕開啟中。
- 再點一次圖示、點選單外面或按 Esc 都會關閉選單；打開或關閉選單本身不會開關字幕。
- 在 YouTube 影片頁按 **Alt+C** 可直接開啟或關閉雙語字幕。游標在文字輸入欄位時，快捷鍵不會觸發。
- 選單各列：
  - **雙語字幕**：開關雙字幕。
  - **翻譯**：右側顯示目前的翻譯等級與模型，例如「AI · deepseek-v4.1-flash」，點進去可切換等級（見「翻譯等級」）。
  - **字幕時間**：右側顯示「原始」或「提早 0.5 秒」等，點進去可微調（見下文）。沒有時間碼時無法選取。
  - **匯入英文 SRT／VTT**：選擇字幕檔。
  - **API key 與模型設定…**：打開擴充功能的設定頁。
  - 最底下的小字顯示目前的字幕來源，以及是否含字詞時間碼。
- 套件會打開播放器 CC，沿用播放器字幕請求的憑證，直接下載英文字幕軌（json3，毫秒級時間碼）。有人工英文字幕時優先使用，沒有才用自動產生的英文字幕。播放器畫面上選的是哪種語言都不影響，並會提前翻譯接下來約一分鐘的句子。
- 讀不到字幕軌時，會改讀 YouTube 逐字稿面板（只有秒級時間碼）。再讀不到，才用播放器 CC 即時合句，這時字幕會比聲音晚，因為要等句尾或停頓。
- 若播放器讀不到字幕，可用 DownSub 下載英文 SRT。在套件提示卡或選單中點「匯入英文 SRT／VTT」，選擇檔案，再到選單打開「雙語字幕」。
- 在選單關掉「雙語字幕」開關即可關閉雙字幕。

從字幕軌取得的字幕會依實際字詞時間斷句：人工字幕依標點斷句，句子落在一行中間時，依字元位置推算該行內的時間；自動字幕沒有標點，但每個字都有時間碼，會在說話停頓處斷句，句子過長時切在後半段最長的停頓。每句從第一個字開始時出現，最後一個字講完後停留約 0.6 秒，或在下一句開始時換掉。

SRT 和 YouTube 逐字稿會先按句子重新組合，再依時間碼整句顯示。逐字稿的結束時間會依下一段起點推算。若兩句共用一個字幕片段，分界會在該片段的時間內估算。有時間碼時，完整英文會在起始時間顯示，繁中翻好後只補到仍在畫面上的同一句。缺少時間碼時，即時 CC 需要接到句尾或停頓後才能顯示整句。

選單最底下的小字顯示目前字幕來源。播放時間碼字幕時，可在選單的「字幕時間」把字幕提早或延後，每次 0.5 秒，最多 ±10 秒；「重設」回到原始時間碼。切換影片會重設微調。若使用即時 CC，套件會在下一句開始收到文字時移除前一句，再等待下一整句。

## 翻譯等級

在選單點「翻譯」，可以直接選擇 Chrome 內建翻譯或 AI 模型。目前使用的選項會打勾，播放中切換會立即生效：

- **基本**：Chrome 內建翻譯，在本機執行，不需要 API key。
- **AI**：透過 OpenRouter 呼叫 AI 模型，預設為 DeepSeek（`deepseek/deepseek-v4.1-flash`），依用量計費，一部 10 分鐘的影片約 0.2 美分。以整段字幕為單位分批翻譯，語氣較自然，換句時通常已翻好。剛開始或跳轉後先送約 8 句，讓第一句盡快出現，之後每批約 20 句。選單裡也可改用 Qwen 或 Claude Sonnet 等其他 OpenRouter 模型。

舊版的「AI 免費」（Gemini）與「AI 進階」已合併為「AI」；原本選了其中一個的設定會自動改成「AI」並使用 DeepSeek。

API key、模型與預設等級在擴充功能的設定頁設定：在選單點「API key 與模型設定…」，或到 chrome://extensions → 雙語字幕 → 詳細資料 → 擴充功能選項。在設定頁改了模型，選單上的標籤會跟著更新。OpenRouter 名稱以 `:free` 結尾的模型有次數限制，用完時請求會失敗。

使用「載入未封裝項目」安裝時，也可在 `manifest.json` 同一層建立 `.env`，填入 OpenRouter 金鑰：

```dotenv
OPENROUTER_API_KEY=
```

會優先使用 `.env` 的非空白金鑰，留白時使用設定頁存過的值。舊的 `GEMINI_API_KEY` 會被忽略，可以刪除。初次更新程式後請在 `chrome://extensions` 重新載入擴充功能，再重新整理 YouTube。`.env` 已加入 Git 忽略清單，製作分享用 ZIP 時也請排除這個檔案。

在設定頁的「播放器模型選單」可勾選要顯示的內建模型。按「儲存」後，已開啟的播放器選單會同步更新。自行輸入的模型也可以選擇。「測試翻譯」會儲存設定，並用和播放器相同的流程翻譯兩句測試字幕；失敗時會顯示原因，例如「測試失敗：AI 服務暫時無法使用（HTTP 503）。」預設清單由 `settings.js` 的 `MODEL_CATALOG` 定義，隨套件新版發布。

服務暫時過載（HTTP 502／503／504）時，背景程式會在 1 秒、3 秒後各自動重試一次；包含重試在內，一次請求最多等 25 秒。AI 翻譯失敗時（沒有 key、key 無效、超過次數限制、網路錯誤、超過 25 秒沒有回應等），套件會自動改用內建翻譯並顯示提示（約 6 秒後自動消失），字幕不會中斷。若內建翻譯也無法啟動（例如從未下載過語言模型），會只顯示英文字幕；這時可在選單把翻譯切到「基本」，再重新開啟「雙語字幕」下載模型。退回後，選單的「翻譯」仍會顯示所選的 AI 模型，下一行會標示失敗原因與目前狀態，例如「AI 回應逾時，改用 Chrome 內建」「找不到這個模型，改用 Chrome 內建」或「API key 無效或沒有權限，僅顯示英文」。若顯示「擴充功能已更新，請重新整理頁面」，代表擴充功能重新載入過，重新整理 YouTube 頁面即可。在「翻譯」子選單再點一次原本的 AI 等級即可重試。選擇 AI 等級時，英文字幕會送到 OpenRouter 翻譯；API key 只保存在本機，只有背景程式與選項頁會讀取。

HTTP 429 回應會提示服務限制請求，模型仍可手動重試。OpenRouter 回傳 HTTP 402（帳戶餘額不足）時，會提示餘額不足並改用 Chrome 內建翻譯，同一個服務商的所有模型都會在翻譯子選單標示並停用；因同時進行中的請求暫時超出餘額而回的 402 則視為限制請求。加值後，可重新整理影片頁面再試。更新 API key 也會解除本頁的停用狀態。

## 查單字、複製

- 滑鼠移到字幕上時，該句會暫停換句（影片照常播放），移開後跳回目前的句子。
- 點一下英文單字或中文詞就會複製該字；拖曳選取一段文字會複製選取的部分；連點三下複製整行。
- 複製後字幕上方會短暫顯示「已複製：…」。點字幕不會讓影片暫停或全螢幕，右鍵會出現瀏覽器的選單。

## 單字高亮

在選單點「匯入英文 SRT／VTT」可匯入字幕檔。有內嵌字詞時間碼的 VTT 會使用原始標記，缺少標記的字詞會依所在時間區間估算。只有即時 CC 時會顯示整句，但無法依發音逐字高亮。逐字稿時間區間有空檔時，若播放器當下仍有 CC，會用當前 CC 補位。
