# bilingual-captions-extension

在桌面版 Chrome 的 YouTube 播放器顯示英文及繁體中文字幕。預設由 Chrome 在本機翻譯，首次使用可能需要下載語言模型；也可改用 AI 翻譯（見「翻譯等級」）。

## 安裝或更新

將 ZIP 解壓至 Side_Project。若已安裝舊版，可以用新版檔案更新原目錄，再到 chrome://extensions 點套件卡片上的重新載入。新安裝則開啟開發人員模式，選「載入未封裝項目」，指定專案資料夾。完成後重新整理 YouTube。

## 使用

- 將滑鼠移到影片上，點右下角控制列的雙語字幕圖示，會在圖示上方打開「雙語字幕選單」（外觀仿 YouTube 的設定選單）。打開「雙語字幕」開關，然後播放。圖示下方有底線時表示雙語字幕開啟中。
- 再點一次圖示、點選單外面或按 Esc 都會關閉選單；打開或關閉選單本身不會開關字幕。
- 選單各列：
  - **雙語字幕**：開關雙字幕。
  - **翻譯**：右側顯示目前的翻譯等級與模型，例如「AI 免費 · gemini-3.8-flash」，點進去可切換等級（見「翻譯等級」）。
  - **字幕時間**：右側顯示「原始」或「提早 0.5 秒」等，點進去可微調（見下文）。沒有時間碼時無法選取。
  - **匯入英文 SRT／VTT**：選擇字幕檔。
  - **API key 與模型設定…**：打開擴充功能的設定頁。
  - 最底下的小字顯示目前的字幕來源，以及是否含字詞時間碼。
- 套件會打開播放器 CC，沿用播放器字幕請求的憑證，直接下載英文字幕軌（json3，毫秒級時間碼）。有人工英文字幕時優先使用，沒有才用自動產生的英文字幕。播放器畫面上選的是哪種語言都不影響，並會提前翻譯接下來約一分鐘的句子。
- 讀不到字幕軌時，會改讀 YouTube 逐字稿面板（只有秒級時間碼）。再讀不到，才用播放器 CC 即時合句，這時字幕會比聲音晚，因為要等句尾或停頓。
- 若播放器讀不到字幕，可用 DownSub 下載英文 SRT。在套件提示卡或選單中點「匯入英文 SRT／VTT」，選擇檔案，再到選單打開「雙語字幕」。
- 在選單關掉「雙語字幕」開關即可關閉雙字幕。

從字幕軌取得的字幕會依實際字詞時間斷句：人工字幕依標點斷句，句子落在一行中間時，依字元位置推算該行內的時間；自動字幕沒有標點，但每個字都有時間碼，會在說話停頓處斷句，句子過長時切在後半段最長的停頓。每句從第一個字開始時出現，最後一個字講完後停留約 0.6 秒，或在下一句開始時換掉。

SRT 和 YouTube 逐字稿會先按句子重新組合，再依時間碼整句顯示。逐字稿的結束時間會依下一段起點推算。若兩句共用一個字幕片段，分界會在該片段的時間內估算。有時間碼時，完整英文會在起始時間顯示，繁中翻好後只補到仍在畫面上的同一句。缺少時間碼時，即時 CC 需要接到句尾或停頓後才能顯示整句。

選單最底下的小字顯示目前字幕來源。播放時間碼字幕時，可在選單的「字幕時間」把字幕提早或延後，每次 0.5 秒，最多 ±10 秒；「重設」回到原始時間碼。切換影片會重設微調。若使用即時 CC，套件會在下一句開始收到文字時移除前一句，再等待下一整句。

## 翻譯等級

在選單點「翻譯」，可切換三個翻譯等級（AI 等級會標出目前使用的模型），目前的等級會打勾，播放中切換會立即生效：

- **基本**：Chrome 內建翻譯，在本機執行，不需要 API key。
- **AI 免費**：預設使用 Gemini 免費層，以整段字幕為單位分批翻譯，語氣較自然，換句時通常已翻好。剛開始或跳轉後先送約 8 句，讓第一句盡快出現，之後每批約 20 句。
- **AI 進階**：預設透過 OpenRouter 使用較強的付費模型，依用量計費。

API key、模型與預設等級在擴充功能的設定頁設定：在選單點「API key 與模型設定…」，或到 chrome://extensions → 雙語字幕 → 詳細資料 → 擴充功能選項。在設定頁改了模型，選單上的標籤會跟著更新。Gemini 免費層與 OpenRouter 名稱以 `:free` 結尾的模型都有次數限制，用完時請求會失敗。

AI 翻譯失敗時（沒有 key、key 無效、超過次數限制、網路錯誤、超過 25 秒沒有回應等），套件會自動改用內建翻譯並顯示提示（約 6 秒後自動消失），字幕不會中斷。若內建翻譯也無法啟動（例如從未下載過語言模型），會只顯示英文字幕；這時可在選單把翻譯切到「基本」，再重新開啟「雙語字幕」下載模型。退回後，選單的「翻譯」會顯示「基本（AI 已暫停）」或「僅英文（AI 已暫停）」；在「翻譯」子選單再點一次原本的 AI 等級即可重試。選擇 AI 等級時，英文字幕會送到所選的服務（Gemini 或 OpenRouter）翻譯；API key 只保存在本機，只有背景程式與選項頁會讀取。

## 查單字、複製

- 滑鼠移到字幕上時，該句會暫停換句（影片照常播放），移開後跳回目前的句子。
- 點一下英文單字或中文詞就會複製該字；拖曳選取一段文字會複製選取的部分；連點三下複製整行。
- 複製後字幕上方會短暫顯示「已複製：…」。點字幕不會讓影片暫停或全螢幕，右鍵會出現瀏覽器的選單。

## 單字高亮

在選單點「匯入英文 SRT／VTT」可匯入字幕檔。有內嵌字詞時間碼的 VTT 會使用原始標記，缺少標記的字詞會依所在時間區間估算。只有即時 CC 時會顯示整句，但無法依發音逐字高亮。逐字稿時間區間有空檔時，若播放器當下仍有 CC，會用當前 CC 補位。
