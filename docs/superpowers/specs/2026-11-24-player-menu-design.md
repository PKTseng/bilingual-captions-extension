# 播放器選單設計

日期：2026-11-24
規模：小型變更（簡短設計）

## 目的

使用者要在 YouTube 播放器上直接選翻譯等級，就像點 YouTube 齒輪那樣跳出選單。現在左鍵是開關、右鍵才開一張很難發現的卡片，模型只能在設定頁看。

## 目標

- 點播放器上的雙語字幕圖示，在圖示上方打開仿 YouTube 設定選單的面板；再點一次、點選單外面或按 Esc 關閉。
- 主選單各列：
  - **雙語字幕** 開／關開關（取代原本左鍵的開關，圖示底線照舊表示開啟中）
  - **翻譯 >** 目前等級，例如「AI 免費 · gemini-3.8-flash」
  - **字幕時間 >** 「原始」或「提早 0.5 秒」等；沒有時間碼時變灰
  - **匯入英文 SRT／VTT**
  - **API key 與模型設定…** 打開設定頁
  - 最底下一行小字：字幕來源
- **翻譯子選單**：「‹ 翻譯」返回列，加三列「基本（Chrome 內建）」「AI 免費 · 模型」「AI 進階 · 模型」，目前等級打勾；點了切換並回主選單。AI 已退回內建翻譯時，主選單顯示「基本（AI 已暫停）」或「僅英文（AI 已暫停）」，點原本的 AI 等級重試。
- **字幕時間子選單**：「提早 0.5 秒」「延後 0.5 秒」「重設」，範圍維持 ±10 秒。

## 非目標

- 在選單裡直接列出或輸入模型名稱（模型與 key 仍在設定頁）。
- 改動 YouTube 自己的齒輪選單。
- 工具列擴充功能圖示的 popup。

## 反目標

- 選單蓋住字幕或擋住 YouTube 控制列操作後關不掉。
- content script 讀到 API key。

## 做法

- **自建選單（採用）**：在播放器裡建立 `bce-` 前綴的面板，樣式仿 YouTube 設定選單（深色半透明、圓角、列高與字級相近）。
- 塞進 YouTube 齒輪選單：YouTube 會重繪，容易壞，不採用。
- 工具列 popup：不是使用者要的位置，不採用。

## 已決定的設計

- `content.js`：建立選單與子選單、事件；圖示左鍵改為開關選單；移除右鍵卡片（`timing` 面板、`tierRow`、`earlier`／`later`）。右上角提示卡片保留，只放狀態訊息和沒有 CC 時的匯入按鈕。
- 模型名稱：content script 保存一份 `mergeSettings` 後的設定（只用等級與模型名稱），在 `storage.onChanged` 時更新。
- 打開設定頁：content script 送 `{ type: 'bce-open-options' }`，`background.js` 呼叫 `chrome.runtime.openOptionsPage()`。
- `subtitles.css`：選單樣式；`README.md`：使用說明改成選單操作。

## 交給實作者決定

- 選單確切尺寸、動畫、開關的畫法（以 YouTube 設定選單為參考）。
- 選單打開時是否讓 YouTube 控制列保持顯示。
