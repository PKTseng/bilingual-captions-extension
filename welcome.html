雙語字幕安裝好了

在 YouTube 同時顯示原文和繁體中文字幕，支援英文、日文、韓文、泰文影片。

三步開始

  1. 打開一部有字幕的 YouTube 影片。 有人工字幕或自動產生字幕的影片都可以。
  2. 把滑鼠移到影片上，點右下角控制列的 Dual 圖示。 會打開「雙語字幕選單」，外觀和 YouTube 的設定選單一樣。
    Dual CC ⚙ ⛶
  3. 打開「雙語字幕」開關，然後播放。 之後看的影片會自動開啟，直到你把它關掉。
打開 YouTube

更快的操作

  • Alt + C：在影片頁直接開關雙語字幕。
  • +／-／0：放大、縮小、恢復字幕大小。
  • 點瀏覽器右上角的拼圖圖示，把「雙語字幕」釘選到工具列，就能從工具列開關字幕、選原文語言。
  • 滑鼠移到字幕上會停在這一句；點單字可以複製，左邊的按鈕可以重播這句。

選擇翻譯方式

基本（預設）

Chrome 內建翻譯，在你的電腦上執行，免費、不用設定。第一次使用時，Chrome 可能需要下載語言模型，按字幕上方的按鈕即可。

AI

透過 OpenRouter 呼叫 AI 模型，語氣更自然，人名和專有名詞更一致，也能修正自動字幕的標點和錯字。需要自己的 API key，10 分鐘的影片大約 0.2 美分。

設定 API key 與模型

原文語言

預設是「自動」：影片說英文、日文、韓文或泰文時，就用那個語言的字幕當原文；其他語言的影片用英文字幕。也可以在雙語字幕選單或工具列固定成某一種語言。
